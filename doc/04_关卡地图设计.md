# 《大圣劫天记》—— 关卡地图设计文档

---

## 一、设计总览

### 1.1 关卡结构

本作共6大关卡，每关分为4个分段（含中Boss战和关底Boss战）。关卡为横版卷轴，画面以16:9为基准，向左/右单向推进。

### 1.2 场景元素分类说明

为方便美术准备素材，每个关卡的地图元素按以下分类列出：

| 分类 | 说明 |
|------|------|
| 地形 | 地面、平台、墙壁、天花板等通行/碰撞的基础结构 |
| 陷阱 | 对玩家和敌人造成伤害/异常状态的机制物 |
| 可交互物 | 可破坏、可攀爬、可推动的物体 |
| 装饰物 | 纯视觉元素，无碰撞，营造氛围 |
| 机关 | 需要触发或具有循环逻辑的设施 |
| 特殊区域 | 隐藏商店、Boss房、奖励区域 |
