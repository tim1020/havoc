# 《大圣劫天记》—— 第二阶段验收清单

## 一、阶段目标

完成跨关卡资源循环，使第一关具备灵石、回复道具、法宝队列、隐藏商店、过关商店和持久化存档。

## 二、功能验收

### 2.1 全局资源与存档

- [x] 灵石击杀后自动累计并跨关继承
- [x] 救命毫毛最多3根，隐藏商店与过关商店共享每关限购1根
- [x] 法宝栏最多3格，场景拾取满栏时按FIFO顶掉最早法宝
- [x] 商店购买满栏时必须先确认销毁指定法宝
- [x] 生命、灵石、法宝队列、关卡解锁、当前关卡和设置写入JSON存档
- [x] 主菜单无存档时禁用继续游戏，有有效存档时启用

### 2.2 道具与法宝

- [x] 蟠桃回复33点生命
- [x] 猴儿酒回复50点生命并提供10秒双倍移速
- [x] 仙丹回复100点生命
- [x] 火尖枪、乾坤圈、风火轮、紫金铃、毫毛分身、捆仙绳、翻天印均可拾取和使用
- [x] 法宝按C键使用，消费FIFO队首
- [x] 法宝伤害、控制、价格和持续时间来自11个`.tres`资源
- [x] 法宝使用播放有颜色区分的逐帧弧光特效

### 2.3 第一关资源循环

- [x] 第一关固定放置3个蟠桃、火尖枪、乾坤圈和风火轮
- [x] 击败斧牛头目后生成仙丹
- [x] 高台支路石壁可被攻击打破并打开隐藏商店
- [x] 击败混世魔王后自动打开过关商店
- [x] 商店购买与销毁都需要选择后再次确认
- [x] HUD显示全局灵石和3格法宝队列
