# 《大圣劫天记》—— 开发路线图

## 一、基线与推进规则

- 引擎基线：Godot 4.6.3 stable
- 脚本语言：GDScript
- 首发验证平台：macOS 桌面端
- 设计基线：提交 `61faedc` 中的 `doc/00` 至 `doc/06`
- 阶段状态：`未开始`、`进行中`、`自验收`、`已完成`
- 每阶段必须经过“实现 → 自动测试 → 实际运行验收 → 提交推送”流程。
- 阶段自验收通过并推送后直接进入下一阶段，不再等待逐阶段人工确认。
- 全部阶段完成后进行一次统一人工验收。
- 玩法数值统一使用 Godot Resource（`.tres`）维护。
- 阶段所需素材直接生成并纳入仓库，不使用占位图。
- 所有角色使用逐帧动画，至少覆盖静止、移动、攻击、受击和死亡；攻击必须包含逐帧特效。
- 关卡背景与实际行走路线一致；同一关不同场景必须使用不同构图，不重复拼接同一背景。
- 同一水平面的角色使用实体碰撞，不能互相穿透，只能跳过、击退或绕行。

## 三、阶段里程碑

### 第一阶段：通用基础框架与第一关 Demo

目标：建立后续关卡可复用的工程结构，并交付第一关完整纵向切片。

- Godot 项目、输入映射、场景切换和资源加载框架
- 玩家移动、蹲下、跳跃、二段跳、空手三连击、定身术
- 玩家生命、受伤、无敌帧、救命毫毛、死亡与重生
- 第一关四段地图、检查点、陷阱、HUD 和过关结算
- 叛猴喽啰、毒蛇、山猪妖、鹰妖
- 中 Boss 斧牛妖、关底 Boss 混世魔王
- 玩家、敌人、Boss、地图和 UI 实际素材
- 无头自动检查和桌面实际运行验收

详细标准见《08_第一阶段验收清单》。

### 第二阶段：通用道具、经济、商店和存档

目标：完成跨关卡资源循环。

- 灵石获取与累计
- 回复道具、法宝队列、拾取和使用
- 隐藏商店、过关商店和购买限制
- 存档、读档、关卡解锁和设置持久化
- 第一关隐藏区域与道具分布补齐

### 第三阶段：第二、三关与能力转折

目标：完成龙宫、地府连续流程和金箍棒能力升级。

- 第二关东海龙宫及其敌人、Boss、地图、陷阱和素材
- 击败龙王获得金箍棒与披挂
- 第三关起切换棒法、地面御棒和空中追踪蓄力
- 第三关幽冥地府及其敌人、Boss、地图、陷阱和素材

### 第四阶段：蟠桃园

目标：实现第四关和复杂状态交互。

- 方向混乱、伪装、飞行投弹、藤蔓与花粉机制
- 七仙女之首和蟠桃土地公
- 第四关地图、陷阱、素材和数值验收

### 第五阶段：南天门

目标：实现高强度第五关和四大天王连战。

- 云海天梯、碎云、天雷、罡风和南天门
- 后期天兵体系和增长天王幻影
- 四大天王连续战斗与阶段补给

### 第六阶段：凌霄宝殿

目标：完成主线最终关。

- 凌霄长廊、金光阵、九龙壁和追背封印
- 哪吒、二郎神与玉皇大帝
- 最终结算、结局和完整通关流程

### 第七阶段：全局打磨与发布

目标：将完整流程提升到可发布质量。

- 全流程数值和平衡调整
- BGM、SFX、混音和音量设置
- 性能分析、输入体验、可访问性和分辨率适配
- macOS 正式构建；评估 Windows/Web 导出
- 发布说明、已知问题和最终验收记录
