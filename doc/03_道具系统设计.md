#  《大闹天宫》—— 道具系统设计文档

---

## 一、道具系统总览

游戏道具分为四大模块：**灵石（货币/分数）**、**救命毫毛（命数）**、**体力回复道具**、**法宝**。其中法宝系统是核心策略层，鼓励玩家规划资源。

---

## 二、灵石系统

### 2.1 基本规则

灵石同时承担**分数**和**商店货币**两种职能：

- 击杀每个敌人自动获得对应数量的灵石，直接累加到灵石计数，**无实体掉落物**
- 灵石数量显示在 HUD 右上角，关卡间继承
- 用于在隐藏商店购买体力回复道具和法宝

### 2.2 灵石获取量

| 敌人类型 | 灵石获取 |
|----------|----------|
| 普通杂兵 | 少量 |
| 精英/霸体敌人 | 中量 |
| 中Boss | 大量 |
| 关底Boss | 巨额 |

具体数值参见《数值设计文档》。

---

## 三、救命毫毛

### 3.1 基本规则

救命毫毛是角色的**剩余命数**，不同于法宝和体力回复道具，它是一个独立的数值系统。

| 规则 | 说明 |
|------|------|
| 持有上限 | 最多持有 **3根**，超过无法购买/拾取 |
| 初始数量 | 关卡开始时固定数量（具体数值见数值文档） |
| 显示位置 | HUD 左上角，生命条旁边，以猴毛图标表示 |
| 消耗方式 | 血量归零时**自动消耗一根**，角色原地重生（回复全部生命+短暂无敌） |
| 耗尽后果 | 救命毫毛为0时血量归零，则游戏结束 |
| 补充方式 | 商店购买（每关限购1根） |

### 3.2 触发流程

血量归零 → 自动消耗一根救命毫毛 → 播放死亡倒地动画 → 播放重生动画 → 短暂无敌（约2秒）→ 继续战斗

### 3.3 与掉坑的区分

| 场景 | 救命毫毛 | 处理方式 |
|------|----------|----------|
| 血量归零 + 有救命毫毛 | 消耗1根 | 死亡倒地 → 原地重生 |
| 血量归零 + 无救命毫毛 | 不触发 | 游戏结束 |
| 掉入即死区域（血池、云海等） | 不消耗 | 传送回掉坑前位置 + 扣血 |

### 3.4 视觉特效

| 特效 | 触发条件 | 视觉表现 |
|------|----------|----------|
| 救命毫毛消耗 | 死亡倒地前 | 一根金色猴毛从角色身上飘落，化作金光包裹全身 |
| 重生护体 | 重生后短暂无敌 | 角色周身金色光晕，半透明闪烁 |

## 四、体力回复道具

体力回复道具有两种使用路径：场景中拾取后立即生效；商店购买后进入五格物品栏，由玩家长按 C 键主动使用。

### 4.1 道具列表

| 道具 | 图标示意 | 效果 | 获取方式 |
|------|----------|------|----------|
| 蟠桃 | 粉红仙桃 | 回复少量生命 | 场景固定刷新、隐藏商店购买 |
| 仙丹 | 金色丹丸 | 回复全部生命 | 中Boss击败后场景中掉落、隐藏商店购买 |
| 猴儿酒 | 葫芦 | 回复中等生命，并短时间内移动速度大幅提升 | 场景固定刷新、隐藏商店购买 |

### 4.2 设计说明

- **蟠桃**是常规回复手段，分布于各关卡场景中，确保玩家在道中不因消耗战而无力应对Boss
- **仙丹**是中Boss战胜后必然出现的奖励，作为"阶段补给站"，让玩家以满状态面对关底Boss
- **猴儿酒**是战术性回复道具——移速提升可用于快速脱离危险区域，也可配合Boss战爆发走位

## 五、法宝系统

### 5.1 系统规则

| 规则 | 说明 |
|------|------|
| 储存上限 | 最多储存 **3个**法宝 |
| 队列机制 | 先进先出（FIFO）——满3个时捡新法宝，最早的法宝被顶掉 |
| 当前选择 | HUD 用箭头标记当前法宝；短按 **C键** 将队首轮换到队尾 |
| 使用方式 | 长按 **C键** 使用当前法宝或回复物品 |
| 次数限制 | 所有法宝均为一次性道具，使用后消失 |
| 获取方式 | 关卡中固定位置刷新、隐藏商店购买 |

### 5.2 法宝详细效果

#### 火尖枪
| 属性 | 说明 |
|------|------|
| 伤害方式 | 向前方直线穿透飞出，命中一条直线上的所有敌人，每人受一次伤害 |
| 范围 | 横向贯穿大半屏幕 |
| 战术价值 | 适合清理排成一列的敌人，尤其在狭窄通道效果极佳 |
| 视觉特效 | 火焰包裹的长枪高速飞行，命中时火花四溅 |

#### 乾坤圈
| 属性 | 说明 |
|------|------|
| 伤害方式 | 扔出后在前方悬停旋转，持续对触碰的敌人造成伤害 |
| 范围 | 固定位置，旋转半径约1.5个角色身位 |
| 战术价值 | Boss战持续输出——扔在Boss脚下可打满伤害；也可用于封锁狭窄路口 |
| 视觉特效 | 金色圆环高速旋转，触碰时金光迸发 |

#### 风火轮
| 属性 | 说明 |
|------|------|
| 伤害方式 | 沿地面向前滚出，留下火径，敌人踩上持续灼烧 |
| 范围 | 横向约半个屏幕长度的火径 |
| 战术价值 | 区域封锁——Boss移动范围内铺火径，稳定持续输出；清理杂兵群 |
| 视觉特效 | 双轮滚动，火焰轨迹燃烧，地面留下焦痕 |

#### 捆仙绳
| 属性 | 说明 |
|------|------|
| 伤害方式 | 无伤害，纯控制 |
| 效果 | 自动绑住最近1个敌人，普通敌人控制较长时间，Boss控制时间较短 |
| 范围 | 全屏自动锁定最近敌人 |
| 战术价值 | Boss战强力控制——控制窗口足够打出蓄力攻击+三连击；优先捆绑高威胁敌人（如御前侍卫、勾魂使者） |
| 视觉特效 | 金色绳索从法宝中飞出，自动缠绕目标，捆住后敌人被金色锁链束缚 |

#### 翻天印
| 属性 | 说明 |
|------|------|
| 伤害方式 | 扔出后变大从天而降砸地，落点范围高伤害 |
| 范围 | 落点半径约2个角色身位，有冲击波扩散 |
| 战术价值 | 全法宝最高单体伤害——Boss战核心爆发手段；对大体积Boss容易命中 |
| 视觉特效 | 法宝飞向空中变大成巨印，底部有古篆符文，砸地时地面碎裂+冲击波 |

#### 紫金铃
| 属性 | 说明 |
|------|------|
| 伤害方式 | 落地摇响，全屏敌人眩晕+少量伤害 |
| 范围 | 全屏 |
| 战术价值 | 紧急控场——被包围时摇铃解围；配合定身术可形成连锁控制 |
| 视觉特效 | 金色铃铛落地摇动，音波以铃铛为中心全屏扩散，被波及敌人头顶冒星 |

#### 毫毛
| 属性 | 说明 |
|------|------|
| 伤害方式 | 召唤数只小猴子协助战斗，小猴子会自动攻击附近敌人并吸引火力 |
| 范围 | 以玩家为中心召唤 |
| 持续时间 | 小猴子存在一段时间后自动消失，或被敌人击败后消失 |
| 战术价值 | 火力吸引+辅助输出——Boss战中分散Boss注意力、杂兵群中分担压力；小猴子攻击力不高但干扰效果显著 |
| 视觉特效 | 悟空拔下几根猴毛吹出，猴毛化作金光落地变成小猴子，小猴子与悟空形象相似但体型小 |

### 5.3 法宝分类

| 类型 | 法宝 | 用途 |
|------|------|------|
| 伤害型 | 火尖枪、乾坤圈、风火轮、翻天印 | 直接输出伤害 |
| 控制型 | 捆仙绳、紫金铃 | 限制敌人行动 |
| 辅助型 | 毫毛 | 召唤 |

### 5.4 法宝战术规划

| 场景 | 推荐法宝组合 | 理由 |
|------|-------------|------|
| 道中杂兵 | 火尖枪 + 风火轮 + 紫金铃 | 穿透清怪 + 区域封锁 + 紧急控场 |
| Boss战 | 翻天印 + 捆仙绳 + 紫金铃 | 爆发输出 + 控制窗口 + 全屏控场 |
| 杂兵海 | 毫毛 + 乾坤圈 + 风火轮 | 火力吸引 + 持续伤害 + 区域封锁 |

**资源规划建议**：Boss战前尽量攒满3个控制/爆发型法宝。道中获取的控制型法宝（紫金铃、捆仙绳）尽量留给Boss战。

## 六、商店系统

### 6.1 商店类型

游戏中有两种商店入口：

| 类型 | 说明 | 触发方式 |
|------|------|----------|
| 隐藏商店 | 关卡中途的隐藏商店，需打破隐藏墙壁或完成特定条件 | 玩家主动发现/进入 |
| 过关商店 | 每关击败关底Boss后自动进入，是关卡结算的一部分 | 自动触发，不可跳过 |

### 6.2 过关商店

击败每关关底Boss后，画面进入商店界面，玩家可在此消耗灵石购买道具，为下一关做准备。

| 规则 | 说明 |
|------|------|
| 触发时机 | 关底Boss被击败后，结算灵石后自动进入 |
| 可跳过 | 玩家可选择"离开"跳过购买，直接进入下一关 |
| 商品内容 | 与隐藏商店相同（体力回复道具 + 救命毫毛 + 法宝）；回复道具购买后进入法宝栏 |
| 救命毫毛限购 | 全局每关限购1根（隐藏商店和过关商店共享限购次数） |

### 6.3 隐藏商店位置

| 关卡 | 商店位置 |
|------|----------|
| 第1关 | 水帘洞入口——瀑布后打破石壁 |
| 第2关 | 水晶回廊——隐藏珊瑚墙藏宝室 |
| 第3关 | 鬼门关前——击败强制战斗后角落 |
| 第4关 | 瑶池木桥前——莲花荷叶平台后的隐藏小岛 |
| 第5关 | 天梯中途——中Boss战前平台 |
| 第6关 | 凌霄长廊尽头——哪吒战前；玉帝宝座大殿——最终Boss战前 |

### 6.4 商品列表

#### 体力回复道具

|------|------|
| 蟠桃 | 低 |
| 猴儿酒 | 中 |
| 仙丹 | 高 |

#### 救命毫毛

| 商品 | 价格 | 备注 |
|------|------|------|
| 救命毫毛 | 极高 | 每关限购1根，持有上限3根 |

#### 法宝

| 商品 | 价格 |
|------|------|
| 火尖枪 | 低 |
| 乾坤圈 | 中 |
| 风火轮 | 中 |
| 捆仙绳 | 高 |
| 翻天印 | 高 |
| 紫金铃 | 中 |

具体价格参见《数值设计文档》。

### 6.5 法宝栏购买规则

- 法宝或体力回复道具购买后都进入五格物品栏，不会在商店内立即使用
- 法宝栏有空位时，直接购买放入当前空位
- 物品栏已满时，再次确认购买会丢弃队首物品，其余整体前移，新购物品进入队尾
- 销毁操作不可逆，被销毁的物品直接消失
- 购买和销毁操作均需玩家手动确认

## 八、道具与玩法耦合

| 玩法系统 | 耦合道具 | 耦合方式 |
|----------|----------|----------|
| 金箍棒蓄力 | 捆仙绳 | 捆仙绳定住Boss的时间窗口刚好够一次蓄力爆发输出 |
| 法宝队列 | 翻天印、捆仙绳 | 攒满爆发/控制型法宝是Boss战最优解，鼓励玩家在道中克制使用法宝 |
| 陷阱利用 | 风火轮、乾坤圈 | 火径和旋转圈可配合陷阱形成双重伤害区 |
| 灵石经济 | 商店 | 灵石获取鼓励玩家积极战斗，形成"战斗→获得灵石→购买道具→更强战斗"的正循环 |
| 火力分担 | 毫毛 | 召唤小猴子在Boss战和杂兵群中分担压力，适合不擅长应对多目标的玩家 |

## 九、道具系统扩展建议

以下为后续版本可考虑扩展的内容：

1. **法宝合成**：收集特定材料可在商店合成强化版法宝（如"三昧真火·风火轮"，火径持续时间更长）
2. **法宝升级**：使用灵石在商店升级法宝效果（伤害提升、范围扩大、持续时间延长）
3. **变身道具**：特定关卡获得"七十二变"临时道具，变身为特定形态通过特殊地形
4. **连击奖励**：连续击杀N个敌人后灵石获取倍率提升
5. **成就道具**：无伤击败Boss获得"金仙丹"，使用后永久提升少量最大生命
