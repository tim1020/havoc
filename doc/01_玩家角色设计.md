# 《大闹天宫》—— 玩家角色设计文档

---

## 一、角色概述

**角色名称**：孙悟空

**角色定位**：近战爆发型角色，兼具高机动性和控场能力。核心战斗围绕金箍棒蓄力系统展开，操作上限高，新手和高手之间有明显的区分度。


---

## 二、角色技能系统

### 2.1 基础移动

| 操作 | 说明 |
|------|------|
| 左右移动 | 水平方向移动，可配合方向键在攻击中调整身位 |
| 蹲下 | 降低受击判定框高度，可躲避高处飞行道具（如天弓手的上排箭） |
| 跳跃 | 按下跳跃键起跳，空中可再次按下触发二段跳 |
| 蓄力攻击 | 空手释放怒吼；持棒发射三根追踪棒 |

**移动参数**：
- 基础移速：中等偏快
- 跳跃高度：约2.5个角色身高
- 二段跳追加高度：约1.5个角色身高
- 下落速度：正常重力加速度，无缓落

### 2.2 攻击系统

#### 空手期（第1~2关）

孙悟空尚未获得金箍棒，仅以拳脚战斗。

**三连击（连按攻击键B）**：

| 段数 | 招式 | 伤害 | 范围 | 特性 |
|------|------|------|------|------|
| 第一击 | 左拳 | 10点 | 身前近距离 | 出手快，可取消 |
| 第二击 | 右拳 | 10点 | 身前近距离 | 衔接流畅 |
| 第三击 | 转身踢飞 | 10点 | 身前中距离 | 击飞效果，将敌人吹飞约3格距离 |

**空手期蓄力**：长按J蓄力后松开释放怒吼，前方3倍普通攻击距离内的敌兵受到30点伤害。

#### 金箍棒期（第3关起永久）

击败东海龙王后获得金箍棒，此后永久使用棒法战斗。

**三连击（连按攻击键B）**：

| 段数 | 招式 | 伤害 | 范围 | 特性 |
|------|------|------|------|------|
| 第一击 | 横扫 | 15点 | 身前扇形区域 | 可命中多个敌人 |
| 第二击 | 反手横扫 | 15点 | 身后+身前 | 清理前后围攻敌人 |
| 第三击 | 跳起当头一棒 | 15点 | 稍大范围 | 震退周围敌人，小型AOE |

**统一蓄力系统（核心玩法，长按J）**：

无论是否持有金箍棒都可长按J蓄力。蓄力满后松手触发当前武器对应的特殊攻击；蓄力未满时松手触发普通攻击。蓄力期间使用周身弧光表现，不显示独立进度条。

| 状态 | 满蓄效果 | 伤害 |
|------|----------|------|
| 空手 | 怒吼攻击前方3倍普通攻击距离 | 30点 |
| 持棒 | 发射三根自动追踪敌人的金箍棒分身 | 15点×3根 |

**空中攻击**：跳起后短按攻击键向前重击，攻击距离和伤害均为地面普通攻击的2倍。

### 2.3 法术：定身术

| 属性 | 说明 |
|------|------|
| 施放方式 | 同时按下 B + A |
| 消耗 | 最大生命值的20%（20点） |
| 效果 | 全屏敌人瞬间定住（含飞行、钻地中的敌人） |
| 持续时间 | 普通敌人3秒，Boss 1.5秒 |
| 冷却限制 | 定身期间无法再次施放，效果结束后才可再次使用 |
| 战术价值 | 高风险高回报——消耗自身生命换取控场，连续使用会让自己陷入危险 |

## 三、操作方式

### 3.1 按键映射

| 按键 | 功能 | 备注 |
|------|------|------|
| A / D键 | 左右移动 | —— |
| S键 | 蹲下 | 降低受击判定框 |
| K键 / 空格 | 跳跃 | 空中可再按一次触发二段跳 |
| J键 | 攻击 | 松开触发普通攻击；长按进入蓄力 |
| C键 | 法宝 | 短按切换当前法宝；长按使用当前法宝 |
| J + K（同时） | 定身术 | 消耗20点生命 |

### 3.2 进阶操作技巧

| 技巧 | 操作方式 | 说明 |
|------|----------|------|
| 攻击取消跳跃 | 地面攻击中按跳跃 | 连击中可随时跳跃取消，灵活走位 |
| 空中前向重击 | 空中短按攻击 | 向前攻击，距离和伤害均加倍 |

## 四、角色形象与动画设计

### 4.1 角色外观

**空手期形象（第1~2关）**：
- 身着行者布衣，朴素僧袍样式，灰褐色调
- 赤脚或草鞋，手脚毛茸茸的猴爪特征
- 体型精瘦矫健，带有灵长类动物的敏捷感
- 身后隐约可见猴尾

**金箍棒期形象（第3关起）**：
- 行者装束升级：锁子黄金甲（击败龙王后获得）
- 头戴凤翅紫金冠（击败龙王后在龙宫宝库获得）
- 脚穿藕丝步云履
- 金箍棒斜扛肩上，棒身有金色纹路流转
- 整体形象更加威武，毛发色泽更亮

**关键视觉特征**：
- 火眼金睛：眼中时有金光闪过，使用定身术时眼睛短暂发光
- 猴毛细节：手臂和脸颊的毛发纹理清晰，动作时自然飘动
- 表情变化：根据战斗状态切换——平静（探索）→怒目（战斗）→咬牙（受伤）

## 五、设计原则总结

1. **极简操作，深度系统**：6个按键覆盖全部操作，空手与持棒共用一套蓄力操作。
2. **体力换控场**：定身术消耗生命而非蓝条，迫使玩家在"保命"和"控场爆发输出"之间做权衡。
3. **蓄力区分度**：空手满蓄力释放前方怒吼，持棒满蓄力释放三根追踪棒。

## 六、角色状态机制

### 6.1 死亡与重生

角色生命值归零时进入死亡状态，随后在原地重生继续游戏。

| 阶段 | 说明 |
|------|------|
| 死亡倒地 | 播放死亡动画（约20帧），角色跪地倒下；金箍棒期增加棒缩小飞回手中的表现 |
| 重生 | 死亡动画结束后，角色在原地翻身跃起，播放重生动画（约16帧），周身金光环绕 |
| 重生无敌 | 重生完成后，角色获得短暂无敌时间（约2秒），期间半透明闪烁，不受任何伤害 |

**设计说明**：
- 原地重生避免玩家重复跑图，保持战斗节奏连贯
- 短暂无敌给予玩家调整站位和重新组织进攻的缓冲时间
- 重生期间敌人仍可行动，玩家需在无敌结束前找到安全位置

### 6.2 掉坑处理

角色落入即死区域（血池、云海、漩涡等）时，不触发死亡/重生流程，而是直接传送回安全位置。

| 规则 | 说明 |
|------|------|
| 触发条件 | 角色掉入即死区域（非扣血型陷阱，如血池、云海、深渊等） |
| 处理方式 | 瞬间传送回**掉坑前的最后站立位置**，不播放死亡动画 |
| 血量处理 | 扣除一定比例生命值（约1/5最大生命），作为惩罚 |
| 无敌时间 | 传送后短暂无敌（约1秒），防止落地即被连击 |

**设计说明**：
- 掉坑是惩罚而非终结——扣血足以让玩家认真对待，但不打断游戏节奏
- 回到掉坑前位置避免玩家利用掉坑来"传送"到新位置
- 区别于死亡重生，掉坑不触发完整死亡流程，响应更快

### 6.3 救命毫毛（命数系统）

救命毫毛是角色的**剩余命数**，独立于法宝和体力回复道具。HUD左上角以猴毛图标显示剩余数量。

| 规则 | 说明 |
|------|------|
| 持有上限 | 最多持有 **3根** |
| 触发条件 | 血量归零时自动消耗一根救命毫毛 |
| 触发流程 | 播放死亡倒地动画 → 播放重生动画 → 原地重生（回复全部生命）→ 短暂无敌（约2秒） |
| 耗尽后果 | 救命毫毛为0时血量归零，游戏结束（需重新开始当前关卡） |
| 补充方式 | 商店购买（每关限购1根，持有达3根时无法购买） |
| 掉坑 | 掉入即死区域不消耗救命毫毛，仅传送回掉坑前位置 + 扣血 |
