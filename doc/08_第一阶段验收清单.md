# 《大圣劫天记》—— 第一阶段验收清单

## 一、阶段目标

交付一个使用真实素材、能够从主菜单进入并完成第一关的可玩 Demo，同时建立后续关卡可复用的基础框架。

## 二、功能验收

### 2.1 基础框架

- [x] Godot 4.6.3 可正常导入项目，无脚本解析错误
- [x] 主菜单可以开始游戏
- [x] 第一关可以暂停、重新开始和返回主菜单
- [x] 输入动作集中配置，不在业务脚本中读取物理键码
- [x] 玩家、敌人和关卡数值来自 `.tres` 资源

### 2.2 玩家

- [x] 支持左右移动、蹲下、跳跃和二段跳
- [x] 支持空手三连击，伤害为每段10点
- [x] 普通攻击按下时不触发，松开时结算；长按不会连续攻击
- [x] 长按0.75秒进入蓄力，松开造成30点伤害
- [x] 支持定身术，消耗20点生命
- [x] 支持受伤、0.5秒无敌帧和击退
- [x] 初始3根救命毫毛，死亡后原地重生并回复满生命
- [x] 毫毛耗尽后重新开始当前关卡
- [x] 玩家实际素材覆盖空手期基础动作、攻击、受伤、死亡和重生

### 2.3 第一关

- [x] 包含花果山脚、藤蔓区、水帘洞入口、水帘洞内部四段
- [x] 摄像机跟随玩家且不越出关卡边界
- [x] 地面、平台、陷阱和检查点碰撞正确
- [x] 所有可站立地面和平台顶边都有清晰提示线
- [x] 叛猴喽啰、毒蛇、山猪妖、鹰妖均可战斗
- [x] 斧牛妖中 Boss 可完成战斗
- [x] 混世魔王关底 Boss 有两个阶段并可击败
- [x] 4类普通敌人和2个 Boss 均有待机、移动、攻击和受击状态动画
- [x] 敌人受击时有闪白、后仰、形变和击退反馈
- [x] 敌人受击后右上显示名称、当前生命和实时血条
- [x] 击败混世魔王后出现过关结算

### 2.4 素材

- [x] 玩家、4类普通敌人和2个 Boss 使用生成后的正式位图素材
- [x] 第一关背景、地形、陷阱和 HUD 使用正式素材
- [x] 项目中不存在用于交付的纯色方块、默认图标或占位图片
- [x] 透明素材边缘无明显色键残留

## 三、质量验收

- [x] 无头启动和资源导入检查通过
- [x] 自动化核心逻辑检查通过
- [x] 实际启动游戏检查主菜单、操作、战斗和过关流程
- [x] 运行日志无脚本错误和资源缺失
- [x] 关键画面截图留档
- [x] 阶段改动提交并推送到 `feat/1.0`

## 四、阶段门禁

全部必需项完成后：

1. 更新《07_开发路线图》第一阶段状态为“待验收”。
2. 记录测试命令、实际运行结果和提交哈希。
3. 推送 `feat/1.0`。
4. 暂停开发，等待用户确认。
5. 用户确认后将第一阶段状态改为“已完成”，再进入第二阶段。
