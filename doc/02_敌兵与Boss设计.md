# 《大闹天宫》—— 敌兵与Boss设计文档

---

## 一、设计总览

本作共有6大关卡，每关包含4种普通敌兵和至少1场中Boss、关底Boss战；第五关为四大天王连战，第六关为二郎神、玉皇大帝连战。敌人设计遵循以下原则：

- **渐进式复杂度**：前两关敌人攻击模式简单（单次攻击），后期敌人引入连招、远程、地形互动
- **陷阱对敌人同样有效**：所有场景陷阱均可用于对付敌人，鼓励玩家利用环境
- **霸体机制**：少数敌人（如山猪妖、天门力士）具有霸体，不会被普通攻击打断；第一、二关需利用陷阱、走位或法宝，第三关起可追加使用金箍棒蓄力攻击
- **行为可读性**：所有敌人攻击前均有明确的前摇动画，给予玩家反应时间

### 1.1 数值等级说明

本文档中血量与攻击力使用等级描述，具体数值参见《数值设计文档》。

| 等级 | 说明 | 适用对象 |
|------|------|----------|
| 小 | 血量/攻击力偏低 | 前中期脆皮杂兵、远程干扰型敌人 |
| 中 | 血量/攻击力中等 | 标准杂兵、有一定威胁的敌人 |
| 大 | 血量/攻击力偏高 | 后期杂兵、霸体敌人、高威胁精英 |
| 中Boss级 | 中Boss专属 | 各关中Boss |
| Boss级 | 关底Boss专属 | 各关关底Boss |
| 最终Boss级 | 最终Boss专属 | 玉皇大帝（含护盾）、二郎神 |

### 2.2 中Boss：混世魔王副将（斧牛妖）

| 属性 | 说明 |
|------|------|
| 血量 | 中Boss级 |
| 攻击力 | 中Boss级 |
| 攻击模式 | ① 三板斧三连（横扫→上挑→重劈）；② 牛角冲撞（短距离冲刺）；③ 咆哮召唤叛猴×2 |

**战斗策略**：三连斧节奏固定，可在第三下重劈硬直时输出；召唤小兵时优先清理，避免被夹击；空手期战斗，考验玩家基础操作。

### 2.3 关底Boss：混世魔王

| 属性 | 说明 |
|------|------|
| 血量 | Boss级 |
| 攻击力 | Boss级 |
| 攻击模式 | ① 大刀三连（横扫→纵劈→回旋斩）；② 咆哮召唤叛猴×3；③ 红刀状态（半血触发，攻击力+50%，速度+30%） |

**战斗阶段**：
- P1（100%~50%）：大刀三连节奏慢，咆哮招小兵后有大硬直

- 建议在P1阶段尽量攒蟠桃，P2阶段用定身术控场爆发

## 八、敌人AI行为设计总则

### 8.1 通用AI规则

| 规则 | 说明 |
|------|------|
| 攻击前摇 | 所有敌人攻击前均有可辨识的前摇动画（0.3~1.2秒不等），给予玩家反应时间 |
| 受击硬直 | 普通敌人受击有短暂硬直（霸体敌人除外），可被三连击锁住 |
| 仇恨范围 | 每个敌人有独立的"发现范围"，进入范围后开始行动 |
| 脱战重置 | 远离敌人一定距离后，敌人回到初始位置（Boss战除外） |
| 陷阱交互 | 所有陷阱对敌人同样有效，可引诱敌人踩入 |
| 同屏上限 | 同屏敌人数量一般不超过6个，保证性能与可读性 |

### 8.2 Boss AI 设计原则

1. **阶段化战斗**：每个Boss至少2个阶段，半血触发形态/技能变化
2. **攻击循环**：Boss技能按固定顺序循环，熟练后可预测
3. **硬直窗口**：每个技能后留1~2秒硬直，是玩家输出窗口
4. **可读性优先**：大招前必有明显蓄力/预警，不死于"看不懂"
5. **渐入佳境**：Boss难度随关卡递增，最终Boss是多机制的综合考验

### 8.3 敌兵类型总结

| 类型 | 代表敌人 | 设计意图 |
|------|----------|----------|
| 近战基础型 | 叛猴喽啰、骷髅兵、虾兵 | 让玩家练习基础攻击节奏 |
| 霸体冲锋型 | 山猪妖、天门力士 | 前期练习陷阱与走位，获得金箍棒后可用蓄力/法宝应对 |
| 飞行型 | 鹰妖、蟠桃童子 | 练习空中攻击和蓄力追踪 |
| 特殊机制型 | 游魂、桃妖、御前侍卫 | 增加战斗多样性，打破常规 |
| 远程干扰型 | 天弓手、云中仙 | 迫使玩家注意走位和距离 |
| 控制型 | 勾魂使者、龙宫侍女、散花仙女 | 考验玩家应对异常状态的能力 |
| 防御型 | 骷髅兵、蟹将 | 鼓励绕后或蓄力破防 |
| 高血量型 | 护园力士、黄巾力士 | 耐力战，测试持续输出能力 |
