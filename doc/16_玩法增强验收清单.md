# 玩法增强验收清单

## 目标

补齐通关反馈、法宝可视效果、远程敌技、商店信息、蟠桃园检查点和第三关能力衔接，使六关流程中的关键状态变化可见、可操作、可验证。

## 验收结果

- [x] 关卡通过时玩家立即停止操作，播放角色胜利动作和中央通关动画，动画结束后显示结算面板
- [x] 关卡通过时玩家生命立即恢复至最大值
- [x] 投掷类法宝生成独立可见节点，并从玩家位置向目标运动后结算伤害或控制
- [x] 毫毛生成三只可见猴子分身，自动接近并攻击敌人
- [x] 多名精英和 Boss 可释放远程投射物，Boss 强化阶段释放三发扇形弹幕
- [x] 蟠桃、猴儿酒和仙丹从商店购买后进入五格物品栏，不在购买时立即回复
- [x] 短按 C 轮换当前法宝，长按 C 使用当前法宝；HUD 用箭头标记当前选择
- [x] 商店 11 件商品均显示独立图片
- [x] 蟠桃园中段检查点激活后，死亡重生位置更新到检查点
- [x] 全流程可蓄力；第三关起切换金箍棒三追踪棒效果并使用生成的 `player_staff_atlas.png` 持棒角色图集
