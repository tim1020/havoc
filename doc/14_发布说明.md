# 《大圣劫天记》1.0 发布说明

## 版本范围

1.0 提供完整六关主线，从花果山起步，依次经过东海龙宫、幽冥地府、蟠桃园、南天门，最终进入凌霄宝殿挑战哪吒、二郎神与玉皇大帝。

## 核心内容

- 玩家支持移动、蹲下、二段跳、松开触发的三连击、第三关起长按蓄力、定身术与三格法宝栏。
- 获得金箍棒后切换棒法、御棒飞行、下劈和空中追踪棒。
- 短按 C 切换当前法宝，长按 C 使用；投掷法宝具有可见弹道，毫毛会召唤三只猴子自主攻击。
- 商店 11 件商品均有独立图片，购买的体力回复道具进入法宝栏后再主动使用。
- 六关均包含独立四分区构图、与碰撞面对齐的可站立顶边线、陷阱、拾取物和 Boss 战。
- 所有玩家与敌人核心状态均使用实际逐帧动画，覆盖静止、移动、攻击、受击和死亡；攻击包含逐帧特效。
- 同层玩家与敌人启用实体碰撞，不能直接穿透。
- 提供灵石、商店、法宝、救命毫毛、关卡解锁与 JSON 存档。
- 提供菜单及六关独立 BGM，以及攻击、受击、拾取、胜利音效。
- 关卡通过时播放角色与中央文字动画并回满生命；蟠桃园中段设有死亡重生检查点。
- 多名精英和 Boss 支持远程投射物，Boss 强化阶段会释放三发扇形弹幕。
- 暂停菜单支持总音量、音乐、音效和减少界面动画设置，设置随存档保存。

## 构建信息

- 引擎：Godot 4.6.3 stable
- 首发验证平台：macOS
- 架构：x86_64 + arm64 universal
- 应用标识：`com.tim1020.havoc`
- 版本：`1.0.0`
- 本地构建产物：`builds/Havoc.app`

## 已知限制

- 当前 macOS 构建未进行开发者签名和 Apple 公证，跨设备分发时可能触发 Gatekeeper 提示。
- Windows 与 Web 导出未纳入 1.0 首发验收，不能视为已支持平台。
- 音乐与音效为首版简化素材，后续可在不改玩法逻辑的前提下替换同路径资源。
- 自动测试为快速退出的场景测试，Godot 在部分测试进程结束时会报告资源清理警告；所有功能断言和导出后二进制启动均通过。
